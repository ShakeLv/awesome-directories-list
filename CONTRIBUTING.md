# Contributing

Thanks for helping keep this list accurate.

- Found a dead link or a wrong status? Open an issue with the entry name and URL.
- Want to add a directory or launch platform? Open a PR that adds a row to `data/directories.csv` (and mention it in the issue). Entry criteria: it must be a real directory or launch platform that accepts product submissions, and its website must be reachable.
- Status columns are refreshed by a periodic automated check; manual corrections are welcome in the meantime.
