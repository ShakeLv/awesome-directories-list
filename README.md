## Methodology

This list was assembled on 2026-10-12 by collecting public directory lists (see credits), merging duplicates by domain, and then running an automated HTTP check against every entry, following redirects, from a real browser user agent. Statuses reflect that check:

- **✅** the site answered with a success status.
- **⚠️ blocked** the site is alive but refuses automated requests (bot protection). It is marked for manual review; most of these load fine in a browser.
- **❌** the site did not answer (DNS failure, timeout, or an error page like 404).

DR values come from the source lists (Ahrefs Domain Rating where stated) and may drift over time. Pricing reflects the cheapest submission route noted by the sources; many directories offer free and paid tiers.
